## ✨ Violet Lite는 무엇이 다른가요?

기존 오리지널 Violet의 불편하고 답답했던 점들을 대폭 뜯어고쳐, **누구나 설치하자마자 렉 없이 쾌적하게 즐길 수 있도록 새롭게 다시 만든 라이트(Lite) 버전**입니다.

기존에 쓰시던 Violet을 삭제할 필요 없이, **두 앱을 동시에 깔아서 함께 사용**하실 수 있습니다!

## ⚡ 한눈에 보는 핵심 변화 (기존 vs 현재)

| 구분 | 🛑 기존 공식 Violet | 🚀 Violet Lite (현재) |
| :--- | :--- | :--- |
| **첫 실행** | 32MB 거대 데이터 다운로드를 길게 대기 | **기다림 0초! 앱 켜자마자 바로 시작** |
| **작품 목록** | 몇 달 전 멈춰있는 과거 작품만 표시 | **방금 인터넷에 올라온 전 세계 최신작까지 실시간 표시** |
| **언어 버전** | 한국어판이 다른 언어판에 가려져 안 보임 | **한국어 번역본을 포함해 모든 버전이 각각 온전하게 노출** |
| **랜덤 추천** | 최근 며칠 사이 올라온 것들만 계속 맴돔 | **10년 전 숨은 명작부터 최신작까지 골고루 진짜 무작위 추천** |
| **검색창** | 글자 칠 때마다 키보드가 덜컥거리고 버벅임 | **렉 완전 박멸! 글자 치자마자 추천어가 즉시 팡팡** |
| **위치 기억** | 앱 껐다 켜면 어디까지 봤는지 위치를 잃어버림 | **내가 보던 위치를 영구 기억! 원클릭 이어보기 & 위치 뱃지** |
| **북마크 속도** | 북마크가 수백 개 넘어가면 한참 동안 멈춤 | **1,000개가 넘어도 0.02초 만에 시원하게 즉시 열림** |
| **앱 안정성** | 특정 페이지를 열거나 넘길 때 앱 강제 종료 | **튕김 현상, 멈춤, 깜빡임을 완벽히 잡아 부드러운 감상** |

## 🌟 주요 특징 자세히 보기

### 1. 🚀 기다림 없는 0초 시작
앱을 깔고 처음 열 때 거대한 데이터베이스 다운로드 창이 뜨지 않습니다. 설치 후 누르는 순간 곧바로 메인 화면이 열립니다.

### 2. 🌐 방금 올라온 신작까지 실시간 감상
과거에 멈춰있는 예전 목록이 아니라, 전 세계 사이트에 실시간으로 올라오는 최신 작품들을 딜레이 없이 바로바로 찾아볼 수 있습니다.

### 3. 🎲 진짜 무작위(랜덤) 추천 복원
"랜덤 버튼을 눌러도 왜 요즘 올라온 것들만 계속 섞여 나오지?" 하셨던 문제를 완벽 해결했습니다. 10년 전 고전 명작부터 최근 최신작까지 전 시대를 아우르는 진짜 랜덤 추천을 즐겨보세요.

### 4. ⚡ 타이핑 렉 없는 초고속 검색창
검색창에 글자를 한 자 한 자 입력할 때 자판이 버벅거리던 현상을 완전히 없앴습니다. 빠르게 타이핑해도 부드럽게 따라오며 원하는 태그와 작가명을 즉시 추천해 줍니다.

### 5. 📍 내가 보던 자리 그대로! '스마트 이어보기'
수천 개의 작품을 스크롤해서 내려보다가 앱을 끄거나 뒤로 가도 괜찮습니다.
* 직전에 내가 보던 작품 위치를 앱이 알아서 기억합니다.
* 썸네일 아래에 `[📍 마지막 본 위치]` 표시가 붙어 쉽게 찾을 수 있습니다.
* 새로운 작품이 수백 개 추가되어 목록이 밀려나도, 원래 보던 그 작품 위치를 정확히 찾아 스크롤해 줍니다.

### 6. 📅 연도별 / 날짜별 맞춤 검색
원하는 시대나 연도의 작품만 쏙쏙 골라볼 수 있습니다:
* `date:2024` : 2024년에 나온 작품만 보기
* `date:2020~2023` : 2020년부터 2023년 사이의 작품 보기
* `date>=2024` : 2024년 이후 최신작만 보기
* `date<=2018` : 2018년 이전 추억의 고전작만 보기

### 7. 🔖 북마크와 읽음 표시가 안전하게 유지
* 기본 북마크 폴더에 넣어둔 작품은 시간이 지나도 빨간색 읽음 진행도 표시가 사라지지 않고 영구 보존됩니다.
* 북마크 목록이 아무리 방대해도 버벅임 없이 순식간에 열립니다.

### 8. 🛡️ 안심하고 함께 쓰는 듀얼 설치
스마트폰에 이미 설치되어 있는 원래 Violet을 지우지 않아도 됩니다. 두 앱은 서로 완전히 분리되어 있어 둘 다 동시에 깔아두고 자유롭게 비교하며 쓰실 수 있습니다.

## 💡 유용한 검색 꿀팁

검색창에 아래처럼 입력하면 훨씬 편하게 원하는 작품을 찾을 수 있습니다:

| 이렇게 검색해보세요 | 어떤 결과가 나오나요? |
| :--- | :--- |
| `random` | 10년 전 고전부터 최신작까지 전 기간 진짜 무작위 추천 |
| `lang:korean` | 한국어 번역 작품만 모아보기 |
| `lang:korean date>=2024` | 2024년 이후에 나온 최신 한국어 작품 |
| `date:2022~2024` | 2022년부터 2024년 사이에 나온 작품 |
| `artist:작가이름` | 내가 좋아하는 특정 작가의 작품만 모아보기 |
| `female:단독여성` | 한글 태그로도 편리하게 검색 가능 |

## 📲 다운로드 및 설치 방법

1. 상단의 **[최신 앱(APK) 다운로드](https://github.com/hanyuec8/violet/releases/latest)** 링크를 누릅니다.
2. 다운로드된 `violet-lite-v1.34.3.apk` 파일을 스마트폰에서 터치하여 설치합니다.
3. 앱을 실행하면 기다림 없이 즉시 감상하실 수 있습니다!
