기존 Violet의 무겁고 불필요한 기능들을 대폭 덜어내고, 성능 최적화와 편의 기능을 더한 **경량화(Lite) 버전**입니다. (기존 Violet과 동시 설치 가능)

## ⚡ 핵심 차이점

| 구분 | 공식 Violet | Violet Lite |
| :--- | :--- | :--- |
| **초기 실행** | 30MB+ DB 다운로드 대기 | **다운로드 없이 즉시 시작** |
| **신작 필터** | 미지원 | **히토미 독점 신작 단독 필터 (Pupil)** |
| **탐색 위치** | 앱 종료 시 초기화 | **마지막 탐색 위치 영구 기억 & 스마트 점프** |
| **북마크** | 대량 데이터 시 멈춤 | **디스크 캐싱으로 0.02초 즉시 로딩** |
| **코드베이스** | 약 12만 줄의 거대 코드 | **약 7만 줄 (-40%)로 대폭 경량화** |

## ✨ 주요 기능

- **즉시 시작**: 초기 대용량 데이터베이스 다운로드 없이 바로 실행됩니다.
- **Pupil 단독 필터**: 상단 눈동자 아이콘으로 히토미에만 올라온 순수 신작만 선별합니다.
- **스마트 이어보기**: 스크롤 위치 및 마지막으로 본 작품(`[📍 마지막 본 위치]`)을 기억하여 앱 재실행 시에도 바로 복원합니다.
- **태그 즐겨찾기**: 검색창 상단 팝업을 통해 자주 찾는 태그/작가를 원클릭으로 검색합니다.
- **기간 검색**: `date:2024`, `date>=2024`, `date:2020\~2023` 등 직관적인 날짜 필터링을 지원합니다.
- **스마트 북마크**: 미분류 폴더 작품 열람 진행도 영구 보존 및 실시간 로딩 안내를 제공합니다.
